🤖📊 Human Trust Levels in AI Systems – Data Analysis Project
1️⃣ Project Title
Human Trust Levels in AI Systems Analysis
An Excel-Based Data Analytics & Visualization Project
2️⃣ Short Description / Purpose

This project analyzes how different demographic groups perceive and trust AI systems.
The objective is to understand the factors influencing trust levels, including education level, age group and usage experience.

Using data analysis and visualization techniques in Excel, the dashboard highlights patterns in public perception of AI technologies.
The project provides insights into how trust varies across different user segments.

This analysis can help organizations improve AI adoption strategies and user confidence.

📐 Advanced Excel Formulas

✔️ Average Trust Score KPI

✔️ AI Usage Frequency vs Trust Level
✔️ Interactive Filters & Slicers
✔️ Clean & Professional Analytical Dashboard
✔️ Category-wise Trust Distribution

📈 Key Insights

Identified which education groups show higher trust in AI

Compared trust scores across age categories

Analyzed relationship between AI usage and confidence level

Observed variation in perception across demographics
